About the Project

The AI Career & Internship Recommendation System helps students find suitable jobs and internships based on their course, skills, CGPA, and career interests.

The system uses the LinkedIn Job Postings Dataset to recommend the most relevant opportunities for students.

Features

  • Career Assessment
  • Job Recommendation
  • Internship Recommendation
  • Course & Skill Matching
  • LinkedIn Dataset Integration

Technologies Used

  • Python
  • Flask
  • Pandas
  • HTML
  • Bootstrap 5
